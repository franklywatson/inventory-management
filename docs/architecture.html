Data Flow

03
1
User changes a filter
Time Period, Warehouse, Category, or Order Status dropdown in the top filter bar
2
useFilters() updates
Singleton composable holds shared reactive refs — selectedPeriod, selectedLocation, selectedCategory, selectedStatus
3
Component watch fires
Each view watches filter state and calls the relevant api.js method when any value changes
4
Axios sends GET request
api.js builds URLSearchParams (warehouse, category, status, month) and calls the FastAPI endpoint
5
FastAPI filters in memory
apply_filters() and filter_by_month() iterate over the in-memory JSON arrays; skips filters set to "all"
6
Pydantic validates response
Response model enforces types and strips unknown fields before serialising to JSON
7
Vue refs updated
Component assigns response data to reactive refs (allOrders, inventoryItems, etc.) inside try/catch/finally
8
Computed properties re-render
Derived data (totals, filtered lists, chart values) recalculates automatically; Vue updates only the changed DOM nodes
Note: In-memory mock data only — no database, no authentication, no persistence. Demo and training use only.
